# 3D Multiplayer Landscape

Интерактивный 3D-мир на Three.js с процедурным ландшафтом, водой, деревьями, скалами, травой, домиками, облаками, движущимися животными и простым WebSocket-мультиплеером.

## Запуск

```sh
npm install
npm start
```

Откройте `http://127.0.0.1:5173`.

## Управление

`WASD` или стрелки для движения, `Space` для прыжка. Кнопка `↻` генерирует новый мир для всех подключенных игроков. Правый клик по животному открывает экспорт 3D-модели.

## GitHub Pages

Папка `site` может публиковаться на GitHub Pages как статический просмотр 3D-сцены. Для мультиплеера нужен Node-сервер из `server.js`, потому что WebSocket-сервер не работает внутри GitHub Pages.
